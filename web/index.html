Загрузить поисковые запросы

Сначала выберите проект.

Проверьте, что выбранный сайт соответствует проекту. Google: до 1000 запросов; Яндекс: до 500 популярных запросов. До 93 дней за загрузку. Суммы относятся к полученной выборке, а не ко всему сайту. Отчёты сохраняются в разделе «Поисковые данные» выбранного проекта.

Как настроить OAuth-приложения

Для Google скопируйте точный Redirect URI из карточки. У локальной версии и VPS разные адреса возврата.

Google: включите Search Console API, используйте OAuth-клиент типа Web application. Настройте аудиторию и добавьте свой аккаунт в тестовые пользователи, если приложение в режиме Testing. Разрешение — webmasters.readonly. В тестовом режиме Google может потребовать повторный вход через семь дней.

Яндекс: используйте приложение для доступа к API с правом webmaster:hostinfo. Его фиксированный Redirect URI — https://oauth.yandex.ru/verification_code. Нажмите «Подключить аккаунт», откройте Яндекс и введите полученный одноразовый код здесь в течение 10 минут. Права на добавление и подтверждение сайтов не нужны.

Сохраните Client ID и Client Secret в карточке, затем нажмите «Подключить аккаунт». После возврата нажмите «Получить сайты». Данные появятся только для сайтов, к которым у выбранного аккаунта есть доступ.

Токены не возвращаются в браузер и не входят в обычную резервную копию SQLite. На VPS они защищены правами файлов; на Windows — DPAPI текущего пользователя. Удаление подключения стирает локальные настройки и токены, но сохраняет отчёты. Разрешение можно дополнительно отозвать в аккаунте провайдера.
